ArcadeCode: learning to code through play.

An educational pixel-art coding game and my 4th-year BSIT group capstone. Players run and jump through a side-scrolling city and clear each route by solving programming challenges built into the level itself.

AProject overview

ArcadeCode turns beginner programming topics into small, playable puzzles. Instead of reading a question and picking an answer from a list, the player answers by doing something in the level: throwing into the right basket or moving the character the way a line of code says it should.

CGameplay mechanics

Questions you answer with your feet.

Levels are side-scrolling platform stages set against a night-time city skyline and docks. The player walks, jumps and interacts with objects placed in the level. Each object stands for an answer, so the mechanics and the lesson are the same action.

Throw

Basket throw

Throw into the basket that holds the correct answer.

Move

Movement course

Move in the direction the code describes, past barriers and hazards.

Reward

Route progress

Correct actions restore the route and award Code Stars.

// The blank in the hint panel…
___ speed = 2.5f;

// …is a float: the only one of the three that holds a decimal value
float speed = 2.5f;

The challenge teaches a data-type decision in the same context it is used in games: storing a speed that isn't a whole number.

EMovement mechanics

Move left past the signal, then reach the dock.

velocity.x = input * speed;
// input is -1 (left) or +1 (right)
// multiplying by speed sets both direction and how fast the character moves
  1. 1
    Feedback message“Code applied! Route restored.”
  2. 2
    ObjectiveMove left past the signal, then reach the dock
  3. 3
    Direction marker“-1 LEFT” shows the input value in the world
  4. 4
    BarrierA red laser barrier blocks the route
  5. 5
    Enemy & TypeError barHazards the player must get past
  6. 6
    Route progressRoute 4/8 and 17 Code Stars earned

The line of code is the same one that moves the character. When the player sees “-1 LEFT” in the world and the sprite moves left, the multiplication stops being abstract.

Encourage problem-solving

03
